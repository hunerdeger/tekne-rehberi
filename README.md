# Tekne Rehberi

4–20 m motor yatlar için referans kataloğu (175 firma, 1.071 model). Boy, ülke ve tipe göre süzülür; her teknenin yandan görünüş fotoğrafı webden otomatik gelir.

Telefonda açıp paylaş menüsünden "Ana Ekrana Ekle" yapınca uygulama gibi çalışır; bir kez görülen sayfa ve fotoğraflar internetsiz de açılır.
